# Royal Tofu Theme

Shopify theme for royaltofu.com, based on **Horizon 3.2.1**.

Imported from the Shopify theme export `royaltofu-com-new-theme` (29 Sep 2026).

## Structure

- `assets/` – JS, CSS, and static assets
- `blocks/` – theme blocks
- `config/` – `settings_schema.json` and `settings_data.json`
- `layout/` – `theme.liquid` and `password.liquid`
- `locales/` – translations
- `sections/` – theme sections
- `snippets/` – reusable Liquid snippets
- `templates/` – JSON page templates

## Local development

```sh
shopify theme dev --store <your-store>.myshopify.com
```
